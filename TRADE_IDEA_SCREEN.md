# TRADE IDEA SCREEN — standing rule for every MMM / FFF analysis pass

Applied to the 20-row trade table and to Spotlight / Options Ideas before publish.
Set by the handler 2026-09-01. The on-demand analysis pass must run this
screen and state on the page that it was applied.

## 1. Hard exclusions (never listed, long or short)

- Any business that directly engages in, or supplies weapons technology to,
  military operations for Israel. If a name cannot be cleared with a quick
  source check, it is out — absence of evidence is not clearance.
- Weapons-revenue names generally: if the growth story is munitions,
  kinetic systems, counter-UAS "defeat", missiles, or force-protection
  contracts, it does not belong in this book. "Space (not weapons)" means
  launch, satellites, comms, in-space services — not orbital or missile
  defense.
- Companies whose primary revenue is deportation / border-surveillance
  infrastructure (treated as adjacent to the above).

Reviewed and pulled 2026-09-01: SAIC (52% DoD revenue, missile-center and
tactical-threat contracts, DHS/ICE surveillance), DPRO (U.S. Army C-UAS
"kinetic defeat" program, undisclosed foreign military orders).

## 2. Structural tilt (RAMP+)

Every idea gets a sleeve tag in the Notes column:

| Tag | Sleeve |
|---|---|
| [RAMP: AI] | artificial intelligence, AI infrastructure, compute |
| [RAMP: QUANTUM] | quantum computing |
| [RAMP: SPACE] | space — launch, satellite, comms, in-space services (non-weapons) |
| [RAMP: ROBOTICS] | robotics, autonomy (non-weapons) |
| [RAMP: 3D] | 3D / additive industrial manufacturing |
| [RAMP: BLOCKCHAIN] | blockchain, digital assets, mining-to-compute |
| [RAMP: MED] | medical innovation — diagnostics, devices, biotech platforms |
| [MACRO] | index futures, rates, gold — regime trades, not sleeve trades |
| [HEDGE] | defined-risk protection |
| [TACTICAL: x] | non-sleeve opportunistic (energy, rates) — allowed, must be labeled |
| [EXCLUDED-RISK: x] | shown for awareness only, no position |

Rule of thumb: on any day, at least half the actionable (non-NEUT) rows
should carry a RAMP tag. Tactical rows are fine; a table with no sleeve
exposure is a table that forgot the mission.

## 3. Process

1. Build the table.
2. For any defense/government-services/dual-use name: one source check
   (contracts, customer mix). Pull if it hits section 1 or cannot be cleared.
3. Tag every row.
4. Add a SCREEN APPLIED line to Actionables on the page.

## Grounding rule -- confirmed live 2026-09-02, standing as of this date

**No row without a retrieved number.** Every trade-table row must cite either:
(a) a Schwab pivot/VAH/POC/ATR level from the pipeline data,
(b) an FMP quote, sector snapshot, or gainers/losers figure pulled this session, or
(c) a web-search-sourced current price, 52-week range, or specific catalyst (earnings figure, analyst
    action, headline) with the source and approximate date noted.

"Pullback to the 20-EMA" or "below the Aug low" with no actual number behind it is not a level -- it is
a placeholder, and it is not acceptable regardless of which model wrote it.

**If a candidate name cannot be grounded in the time available, it is dropped from the table.**
RAMP-sleeve inclusion does not exempt a name from this bar -- a smaller table with real numbers beats
a full table with filler.

**FMP plan constraint (confirmed 2026-09-02):** this account's FMP tier does not support individual-
equity \quote\ or \	echnicalIndicators\ calls for arbitrary tickers (both return ACCESS DENIED /
no-approval errors). Available FMP tools: \marketPerformance\ (sector snapshots, biggest

stock or ETF, the grounding source is web_search -- pull current price, day range, 52-week range,
and the specific catalyst before writing the row, and cite it as web-sourced with an approximate date.

IONQ, OABI, ARKQ) changed two conclusions on real data -- RKLB flipped LONG to NEUTRAL (a false "RS
holding" claim was corrected by real technicals showing a confirmed downtrend, Strong Sell rating,
-21% since a Sell signal), and OABI flipped from a fabricated pullback setup to an honest no-chase
call once its real move (+22% into 52-week highs) was checked. The rule is confirmed to catch real
errors, not just add decoration. Model used: Claude Sonnet 5.
